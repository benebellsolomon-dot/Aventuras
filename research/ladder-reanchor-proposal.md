# COMPARATIVE_DESCRIPTIONS re-anchor proposal — FULL ladder (v0.3.11)

**Why:** the body-math rebuild (P2) re-anchored the cup *letters* honest-smaller (tier 0→C, 6→DD, 7→E) but the
prose ladder was never re-anchored to follow — so E-cup read as "spilling past gripping fingers" (F/G) and C-cup as
"the faintest suggestion of softness" (AA). This is a **prose calibration only** — the validated
weight/volume/projection/cup math is untouched. This pass covers **all 51 rungs** (good prose at every size).

**Two design goals:**
1. **Calibrated milestones** — the spatial reference should match the size: *hand* (C–FF) → *both hands / arms* (G–HH)
   → *lap / body* (J–L) → *can't lift / floor* (LL–PP) → *environmental* (R–X) → *room / architecture* (ZZ+).
2. **Varied vocabulary** — the current top repeats "warm / yielding / flesh / pooling / spreading" almost every rung;
   the rewrite spreads the imagery (weight, sway, pressure, consequence, the surface it rests on) and rotations of register.

Cup letters run C → X across tiers 0–82, then **ZZ+** (beyond-Z fantasy) for 92+.
